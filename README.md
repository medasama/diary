# 日記帳

PWA ＋ Supabase（GitHub → Vercel）で動く、自分用の日記帳です。

- 合言葉で端末側で暗号化してから送ります（創作帳と同じ合言葉。鍵の作り方は日記専用）
- Supabaseの `diary-entries` は「読む・追加」だけ可能で、書き換えと削除はできません
- 編集するたびに新しい版を1行追加し、アプリはその日の最新版だけを表示します
- 料理記録（`recipe-log`）はその日の分を読み取るだけで、書き込みはしません

## ファイル

| ファイル | 役割 |
|---|---|
| `index.html` | 画面とアプリ本体 |
| `core.js` | 暗号化、CSV取り込み、集計（画面に依存しない部分） |
| `sw.js` / `manifest.webmanifest` / `icon-*.png` | PWA（ホーム画面に追加、オフライン起動） |
| `schema.sql` | Supabaseのテーブル設定 |

## 設置手順

1. **Supabase**：料理記録と同じプロジェクトで SQL Editor を開き、`schema.sql` を貼り付けて Run
2. **GitHub**：新しいリポジトリ（例：`diary`）を作り、このフォルダの中身をすべて置く
3. **Vercel**：そのリポジトリを Import して Deploy（設定は不要。静的ファイルのみ）
4. **初回起動**：合言葉を2回入力（まだ記録がないので確認のため）
5. **取り込み**：スプレッドシートの2025年・2026年を、それぞれ「ファイル → ダウンロード → カンマ区切り形式（.csv）」で保存
   → アプリの ⚙︎ → 「スプレッドシートから取り込む」で2つまとめて選ぶ → 取り込む
6. ⚙︎ → **守りの確認** を押し、「✓ 守られています」と出ることを確認
7. スマホでは Safari の共有ボタン →「ホーム画面に追加」

2台目の端末では、合言葉を1回入力するだけで開けます（既存の記録で合言葉が正しいか確認します）。

## 注意

- **合言葉を忘れると復元できません。** ⚙︎ →「書き出す」で時々バックアップを取ってください（書き出したファイルは暗号化されていません）
- `core.js` の `KDF_SALT_B64` と `KDF_ITERATIONS` は変更しないでください。変更すると、過去の記録が読めなくなります
- Supabase の URL・キーは `index.html` 冒頭の `SUPABASE_URL` / `SUPABASE_KEY` にあります
